为 DeepSeek Harness 留下模型调用的现场。把输入、输出、用量与分层错误放在一起，沿着证据理解一次请求，而不是猜测它发生了什么。

01 / 能力

请求与输出

按轮次查看模型、参数、保留的上下文及输出事件，区分生成、压缩与标题任务。

证据与缺口

展示捕获到的 HTTP、用量及分层异常；未观察到的内容如实标记，不把推测当作根因。

本地归档

SQLite 持久化，按会话浏览与导出。分别看清数据库、详情及旧版备份的占用。

可控保留

按条数、时间与详情容量清理，保护异常请求。自动清理默认关闭，启用后每十分钟检查。

02 / 安装

  1. 下载最新 Release 中的 .tgz 安装包，可使用 SHA256SUMS 校验。
  2. 在 Harness 插件管理中安装该本地包；支持安装规格的入口可使用 Release 资产的完整下载 URL。
  3. 按安装结果激活插件，打开会话追踪视图；全局设置位于“设置 → 请求追踪”。

需要兼容的 DeepSeek Harness 和提供 node:sqlite 的运行时（Node ≥ 22.13）。当前以实验版发布；HTTP 捕获范围随供应商传输与运行时而变化。诊断记录可能包含提示词与输出内容，导出前请自行检查。
